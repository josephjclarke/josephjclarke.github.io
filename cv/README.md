# README 

## Motivation

I have used this CV template for quite some time. It comes from 
[Alessandro Plasmati](https://www.overleaf.com/latex/templates/professional-cv/wvqwpvrmrvkh)
The problem with the template is that it does not respect the separation of content and style,
and as such is a pain to update. My goal is to fix this.
